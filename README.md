# AI Operators · Laboratoria MCP

W 05B.01 sklonuj to repozytorium w folderze przeznaczonym na ćwiczenia.

```bash
git clone https://github.com/asmaestro/aio-mcp.git
cd aio-mcp/gitea-mcp-lab
node scripts/bootstrap.mjs
```

- **05B.01 do 05B.03** · [Gitea i własny serwer MCP](gitea-mcp-lab/README.md). Potrzebujesz Node.js 22 lub nowszego, Dockera z Compose i Claude Code. Zachowaj tę samą kopię między lekcjami.
- **05B.04** · [Kontrola dostępu do dokumentów](demo-mcp/README.md). Z katalogu pierwszego laboratorium przejdź do drugiego poleceniem `cd ../demo-mcp`. Do tego ćwiczenia wystarczy Node.js 22 lub nowszy z npm.

Wszystkie dane do ćwiczeń są fikcyjne. Instrukcję uruchomienia i oczekiwane wyniki znajdziesz w README każdego laboratorium.
